# Coffee Review Prediction

## Overview

This project explores coffee review data and builds machine learning models to predict coffee review scores using Python.

The workflow includes data cleaning, exploratory data analysis, feature preparation, model training, model comparison and evaluation.

## Key Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Feature preparation
- Train/test splitting
- Linear Regression
- Random Forest Regression
- Model comparison
- Regression evaluation using RMSE, MAE and R²

## Tech Stack

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Project Workflow

Data  
→ Cleaning  
→ Exploration  
→ Feature Preparation  
→ Train/Test Split  
→ Model Training  
→ Model Evaluation  
→ Model Comparison

## Models Used

- Linear Regression
- Random Forest Regressor

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
